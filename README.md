# wl-hex

A stacking Wayland compositor written in Rust on Smithay, in the spirit of
[labwc](https://github.com/labwc/labwc) without the Openbox baggage.

Focus: QuickShell and Noctalia, gaming (native, Wine, Proton), and NixOS
flakes with config written in pure Nix. Window decorations are just a border
with configurable width and per-corner radii.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).
