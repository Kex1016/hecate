# wl-hex

A stacking Wayland compositor written in Rust on Smithay, in the spirit of
[labwc](https://github.com/labwc/labwc) without the Openbox baggage.

Focus: QuickShell, gaming (native, Wine, Proton), and NixOS flakes.
Window decorations are just a border with configurable width and per-corner
radii.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).
